# Publisher and recurring-use report template

Use for [PD3 publisher readiness or PD5 independent use](../ROADMAP.md), with
PD2's frozen question/baseline protocol when evaluating useful work. Record local
fixtures, export estimates and independent operation separately. Keep raw results
and unsuccessful attempts; this template does not authorize outreach or spend.
